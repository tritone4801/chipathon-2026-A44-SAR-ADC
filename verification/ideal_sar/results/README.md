## Scope and Limits

The result package validates the ideal ADC/DAC/SAR testbench only. It confirms
that the measurement harness gives ideal results for a known-correct model and
detects injected bad models. It does not claim GF180 transistor-level sampler,
CDAC, comparator, reference, clock, layout parasitic, or SAR ADC power
performance. The power result is only a measurement-chain self-test.

The repository keeps the primary summary CSV at `results/csv/metrics.csv`
instead of `results/metrics.csv` so that all CSV files stay in one subdirectory.
This is the documented layout adjustment allowed by the execution
specification. `metrics.json` and `manifest.json` stay at the result root.

## Measurement Basis

- Differential input convention: `v_diff = VINP - VINN`.
- Waveform input/output comparison convention: use `ideal_DAC(DOUT)` as the ADC output waveform, updated at internal `EOC_INT` and compared with the corresponding sampled input `x[n]`.
- Legal ideal differential range: `-1.70 V <= v_diff <= +1.70 V`.
- Full differential peak-to-peak range: `VFS_diff_pp = 3.4 V`.
- `LSB_diff = VFS_diff_pp / 2^8 = 3.4 V / 256 = 13.28125 mV`.
- Straight-binary ideal quantizer:
  `code = floor((v_diff - v_min)/LSB)`, saturated to `0..255`.
- Transition DAC:
  `V_DAC_threshold(code) = v_min + code*LSB`.
- Reconstruction DAC:
  `V_DAC_center(code) = v_min + (code + 0.5)*LSB`.
- Ideal dynamic plausibility:
  `SNR_ideal = 6.02*N + 1.76 + 20*log10(A_FS_peak)`.
- ENOB conversion:
  `ENOB = (SNDR - 1.76)/6.02`.
- DNL:
  transition width divided by ideal LSB, minus one.
- Endpoint INL:
  cumulative transition error after endpoint gain/offset anchoring.
- Coherent FFT dynamic metrics:
  fundamental, harmonic, noise, SNDR, SNR, SFDR, THD, SQNR, SQDR, and SQNDR
  are calculated from valid held output codes and independent direct/SAR/oracle
  paths.

## Required Schema Check

`csv/metrics.csv` contains the required columns:

```text
category, metric, variant, condition, project_target, ideal_expected, measured,
unit, tolerance, status, method, model_path, raw_data_path, plot_path, tool,
notes
```

It also contains local helper columns `target` and `evidence`. The helper
columns are redundant with existing required fields and make Markdown summary
generation simpler.
