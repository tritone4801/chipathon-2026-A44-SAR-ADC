the saved VMP3 `A44_A` GDS published in the repository.

- [GDS DRC/LVS records](reports/GDS_DRC_LVS)
- [Public KLayout records](reports/PUBLIC_KLAYOUT)

environment. Current repository filenames are listed in
[CURRENT_LAYOUT.json](../../layout/CURRENT_LAYOUT.json).
