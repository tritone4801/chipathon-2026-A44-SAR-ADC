# Review Scope Assumptions

- This GitHub staging update publishes compact simulation result summaries,
  selected plots, and engineering handoff files.
- Verification scripts, generated decks, testbenches, and raw rerun packages
  are intentionally not included in the promoted update.
- The actual CDAC + comparator result rows are limited to the integrated
  review wrapper summarized in `verification/reports/verification_summary.md`.
- The promoted result/plot scope is time-domain waveform evidence and
  frequency-domain spectrum evidence only.
- Static DNL/INL, transfer-curve, protocol, symbol, hierarchy, power, PVT,
  Monte Carlo, layout/PEX/yield, and production-source signoff are not claimed
  by this update.
