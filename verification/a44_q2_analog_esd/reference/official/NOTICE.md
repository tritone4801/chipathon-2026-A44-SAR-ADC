The secondary ESD GDS comes from the SSCS Chipathon 2026 repository at commit
f96d9434d0e258038c5c795d41caae364339eee9, resources/Analog/secondary_ESD_m2.gds.
The original file is retained with the repository Apache-2.0 license. The copy
in gds/components uses 1 nm database units for Magic caching; its physical
polygons and original cell names are unchanged. The matching A44 schematic
uses the actual layout resistor dimensions W=40 um and L=10 um.
